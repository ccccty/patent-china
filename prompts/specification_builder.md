# 说明书

`::: 说明书` 一节 = 发明名称 + 五部分。名称独占一行、不带前缀；五个章标题下直接落正文，不再分小标题；图不进本节，只用「如图N所示」指到第五节。模板该节实测 164 段（正文 121、公式 42、表 1），按此密度配稿。下方代码块内每行即一段，实际写稿时段间空一行；套话段必须逐字照抄，一个字不改。

## 五部分

| 部分 | 写法 |
|------|------|
| 技术领域 | 一句话交代领域与名称，不展开。 |
| 背景技术 | 四段散文写现状与缺口，不点名公开号。 |
| 发明内容 | 「目的—问题—方案—优选—效果—收尾」骨架，与权项同序。 |
| 附图说明 | 引导套话 + 逐条「图N为……；」，末条句号。 |
| 具体实施方式 | 引导套话 + 「请参阅图1-N所示」，按步骤写到可复现。 |

## 技术领域

- 一段、一到两句、不超 60 字，只交代领域与名称。
- 上位领域用行业通用名；不写型号、不写数据来源。
- 主题名称与权利要求 1 逐字一致；自称统一「本发明」（实用新型改「本实用新型」）；不写现状、效果、「本申请」。

```markdown
## 技术领域
本发明涉及<上位领域>技术领域，具体涉及一种<与权1一致的主题名称>。
```

> 本发明涉及农业遥感与智能信息处理技术领域，具体涉及一种基于多尺度非对称融合网络的水稻分布智能制图方法。

## 背景技术

- 4 段、每段 80–160 字，按「现状→要素→前沿→缺口」推进，不列条目、不分小标题；四段落点指向同一技术问题，与发明内容的问题句一一对应。
- 不做分组综述、不写「第一种方案……第二种方案……」、不放对比表；用「难以」「尚未涉及」「无法」陈述客观缺口，不评价他人方案优劣。
- 全文零公开号、零 URL、零「经检索」「对比文件」；查新证据剥离到《查新与区别定位》附件。

```markdown
## 背景技术
<第一段：技术背景与常规手段，落到本领域的实际困难。>
<第二段：拟用的两三类技术要素，各自优势与局限。>
<第三段：近年进展，指出仍存在的具体缺口。>
<第四段：因此，如何……是当前亟需解决的技术难题。>
```

正例（四段，不点名号）：

> 随着遥感技术的发展，多源卫星影像已广泛应用于农业监测等领域，为大范围动态分析提供了数据基础。传统作物制图多依赖单一光学或雷达影像，受限于样本不足、气象干扰和训练样本稀缺，难以实现高效高精度的自动化制图。
>
> 光学影像虽具空间与光谱优势，但易受云雾影响，数据获取不连续；合成孔径雷达影像具全天候成像能力，可补充光学影像的时空缺失；如何高效融合多模态数据、发挥互补优势，是提升识别精度的关键。
>
> 近年来，深度学习方法推动了作物分类的发展，多模态融合网络进一步提升了解译能力。但现有方法多关注模态间特征相关性，忽略模态独立性与类别不平衡，复杂环境下分割效果有限；样本代表性不足与影像污染也制约了早期识别。
>
> 因此，如何在多模态融合中兼顾互补性、独立性与类别平衡，突破样本稀缺与数据污染瓶颈，实现复杂环境下的自动化制图，是当前亟需解决的技术难题。

反例（检索腔，整段删除）：经检索，在数据库中查到三篇相近文献：第一篇公开了……，未涉及……；第二篇公开了……，未涉及……；第三篇公开了……。三篇均未公开本发明的技术手段。连排三篇、逐篇「公开了……未涉及……」，是查新摘录而非背景叙述。

## 发明内容

- 顺序不可调：目的句→技术问题→过渡句→技术方案→优选→有益效果→收尾套话。
- S1…Sn 与权 1 逐字同序同数，各占一段，末条句号、其余分号；每条从属要点写一段「优选地，……。」，与权 2…n 一一对应、同序。
- 有益效果写三条，每条「手段→机制→效果」，能反查到具体步骤；不写实验数据与对比结论。

## 具体实施方式

- 首段逐字照抄引导套话；其后「请参阅图1-N所示，……具体包括以下步骤：」。
- 以「步骤N：<步骤名>，具体步骤如下：」分步，与权 1 的 S1…Sn 同序同数；步骤内再用「（1）（2）」或「具体的，一个实施例中，如图N所示」分层；数据表放本节正文，表题在表上方；末尾两段固定套话，先递进说明、后保护范围，顺序不可换。
- 每个手段写到可复现：输入、处理、输出、关键参数取值齐备；材料没有的硬件与超参数不编造；公式独立成段带编号，正文用「式 (1)」引用。

## 公式

- 公式独占一段，`$$` 起行、公式体、`$$ (1)` 收行；编号贴 `$$` 同行，用半角括号。
- 编号自 (1) 起按出现顺序连续，同一式只编一次号；正文引用写「如式 (1) 所示」「由式 (2) 可得」，编号前留半角空格。
- 公式前必须有一句引导（「……公式如下：」），公式后必须跟「其中，……」解释段。
- 「其中，」段用分号分列符号，末条句号；先含义后量纲，常量取值写在段末；行内符号一律写 `\(x\)`，禁止普通括号包 LaTeX，禁用 `\tilde` `\hat` `\bar`（OMML 常转换失败），改写为 `x'` 或文字表述。

```markdown
将<量>按式 (1) 计算：

$$
\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N}\left(y_i - p_i\right)^2
$$ (1)

其中，\(N\) 为样本总数，\(y_i\) 为第 \(i\) 个样本的真实标签，\(p_i\) 为预测概率，\(\lambda\) 为权重系数，本实施例中取 0.5。
```

## 表格

- 表题只写「表1」，单独一行居中置于表上方，不加长题名；说明文字写进表前的引导句；表前一句点题（「……结果见表1。」），表后接缩写与单位说明段。
- 首行整行加粗，表体小四；表格无框线、居中；同一列单位一致。
- 表内不解释缩写，统一在表下按「缩写—中文含义」列举，并说明量纲与取值范围；表下补「上述数值仅为实施例，不作为对本发明保护范围的限制。」

```markdown
<引导句>……结果见表1。
```
