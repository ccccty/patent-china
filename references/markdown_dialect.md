# Markdown 方言（写稿与出 Word 的接口契约）

`tools/emit_patent_docx.py` 只认这一套标记。写稿时必须按此产出，否则出 Word 会缺章或缺图。

## 五节标记

五个 `:::` 行开启五节，顺序固定，缺一节即报 `PATENT_DOCX_SECTIONS: missing`：

```markdown
::: 摘要
::: 摘要附图
::: 权利要求书
::: 说明书
::: 说明书附图
```

每个 `:::` 行独占一行，前后不要有缩进。节标题由脚本写入页眉，**不要**在正文里再写一遍「说明书摘要」这几个字。

## 各级标题

| 写法 | 出 Word 后 | 用在哪 |
|------|-----------|--------|
| `# 一种……方法` | 三号宋体加粗、居中 | 仅说明书首行，发明名称 |
| `## 技术领域` | 四号宋体加粗、左对齐 | 说明书五个章标题 |
| `### 一级小节` | 四号宋体加粗、左对齐 | 实施例内的可选分组，能不写就不写 |

**不要用 `####` 及更深层**。模板的说明书只有「章 → 正文段落」两级，步骤用 `步骤1：` 这种行内文字，不是标题。

## 正文段落

连续非空行合并为一段，段内换行会被吞掉。**要分段就空一行**。

- 自动套：宋体四号、首行缩进 2 字符、两端对齐、1.5 倍行距。
- 段落第一行不要手打全角空格做缩进——脚本已经缩进。

## 权利要求

序号**手打成文字**，不要用 Markdown 的 `1.` 有序列表（会被转成 Word 自动编号，样式错）：

```markdown
1.一种……方法，其特征在于，包括如下步骤：

S1、……；

S2、……；

2.根据权利要求1所述的一种……，其特征在于，……。
```

每一条权项之间空一行。`S1、` 这类步骤行也各自成段。

## 公式

独立成段，`$$` 起止各占一行，结束行可带编号：

```markdown
$$
\mathcal{L} = \frac{1}{N}\sum_{i=1}^{N}\left(y_i - \hat{y}_i\right)^2
$$ (1)
```

- 带 `(1)` 则出「居中公式 + 右对齐编号」。
- 不带编号就是纯居中公式。
- 行内公式用 `\( … \)`，**禁止**用普通括号包 LaTeX：`(M_{\mathrm{total}})` 在 Word 里是纯文本且常带拼写红线。
- 公式后紧跟解释段，以 `其中，` 开头：

```markdown
其中，\(N\) 为样本总数，\(y_i\) 为第 \(i\) 个样本的真实值，\(\hat{y}_i\) 为预测值。
```

- 禁止 `\tilde` / `\hat` / `\bar`（OMML 转换常失败）。
- 禁止 `^{cpu}` 这类当单位用的上标。

## 表格

表题单独一行写在表**上方**，形如 `表1`（只写编号，说明文字写进正文引导句）：

```markdown
定量对比结果见表1。

表1

| 模型 | 模态 | Kappa | mIoU |
|------|------|-------|------|
| 方法A | opt | 74.06 | 85.72 |
```

- 表头行自动加粗、宋体小四、居中，表格无框线。
- 表下如需说明缩写，另起一段正文。

## 图片

只在 `::: 摘要附图` 和 `::: 说明书附图` 两节里写图。

```markdown
::: 摘要附图
![摘要附图](assets/abstract.png)

::: 说明书附图
![图1](assets/fig1.png)

![图2](assets/fig2.png)
```

- **摘要附图**：`alt` 随便写，脚本不生成图题。
- **说明书附图**：脚本按出现顺序自动写 `图1` `图2` … 作为居中图题，**不要在 md 里手写「图1」这一行**（会重复）。
- 路径相对 Markdown 文件所在目录。图片缺失只报 `IMAGES: missing=N`，不中断出 Word。
- 图号不画进图里。

## 分页

需要强制分页（一般不需要，五节本身各自另起页）：

```markdown
<!-- pagebreak -->
```

## 禁止项

| 禁止 | 原因 |
|------|------|
| HTML 标签（除 `<!-- pagebreak -->`） | 不解析 |
| 脚注 `[^1]` | 不解析，会原样出现在 Word |
| YAML front matter | 会被当成正文段落 |
| 引用块 `>` | 不解析，`>` 会留在文字里 |
| 代码块 ` ``` ` | 会变成等宽块，不像申请书 |
| 链接 `[文字](url)` | URL 属元信息，正文禁用；真要引用写在《查新与区别定位》附件 |
| 正文出现 `CN11xxxxxxA` 公开号 | 公开号只允许出现在查新附件 |
| 行首手打「第X章」「1.1」「3.4.1」 | 章标题固定为五个中文名 |

## 脚本会报的信号

| 信号 | 含义 | 处理 |
|------|------|------|
| `PATENT_DOCX_SECTIONS: missing` | 五节不全 | 补 `:::` 标记 |
| `PATENT_DOCX_MATH: fallback>0` | 有公式 OMML 转换失败 | 简化该式，或改写成文字关系 |
| `PATENT_DOCX_IMAGES: missing>0` | 图路径不存在 | 补图或改路径 |
| `PATENT_LAYOUT: fail>0` | 版式不合规 | 看 `check_patent_docx.py` 的具体条目 |
